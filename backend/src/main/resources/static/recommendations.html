PERSONALISED INSIGHTS

Financial Recommendations

Short, practical suggestions based on your latest financial activity.

How recommendations are generated

FinSight applies rule-based criteria to the analysed transaction data and financial profile.

Budget

Compares spending with the saved budget for each analysed month.

Savings

Looks at income, expenses and the resulting savings rate.

Financial goal

Uses the selected goal period to estimate the effect of the current savings pace.

Spending behaviour

Considers large or unusual non-essential purchases, dominant categories and recurring subscriptions.

Profile context

Uses occupation type and student allowance or employee salary information where provided.
