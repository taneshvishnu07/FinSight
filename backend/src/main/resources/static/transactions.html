Column guide

Use the exact column names in your first row.
ColumnRequirementFormat and accepted valuesExample
DateRequiredYYYY-MM-DD recommended. Also accepts DD/MM/YYYY, MM/DD/YYYY, DD-MM-YYYY, MM-DD-YYYY and YYYY/MM/DD.2026-04-01
DescriptionRequiredText describing the transaction.Monthly Allowance
AmountRequiredNumeric amount. Use a positive amount with Type to identify income or expense.1200.00
TypeOptionalINCOME or EXPENSE. Also accepts CREDIT/DEPOSIT or DEBIT/WITHDRAWAL.INCOME
CategoryOptionalFOOD, GROCERIES, TRANSPORTATION, HOUSING, UTILITIES, HEALTHCARE, ENTERTAINMENT, SHOPPING, EDUCATION, SUBSCRIPTION, TRAVEL, PERSONAL_CARE, FINANCIAL, INVESTMENT, SALARY or OTHER.HOUSING
Payment MethodOptionalCASH, DEBIT_CARD, CREDIT_CARD, BANK_TRANSFER, DUITNOW, E_WALLET, CHEQUE or OTHER.BANK_TRANSFER
Default behaviour
  • If Type is omitted, negative amounts are treated as expenses and positive amounts as income.
  • If Category is omitted, the transaction is assigned to OTHER.
  • If Payment Method is omitted, the system applies its default payment method.
Before uploading
  • Include the column headers in the first row.
  • Upload one CSV file containing at least three months of transactions.
  • Save as CSV (comma-delimited); UTF-8 encoding is recommended.
